# Tests

* Backend unit/integration/API tests: `backend/tests/` (run from `backend/`, see `TESTING.md`)
* Frontend component tests: `frontend/src/**/*.test.tsx(x)` (`npm test` in `frontend/`)
* End-to-end tests: `frontend/e2e/` (`npm run e2e` in `frontend/`)
* Static project validation: `python scripts/verify_project.py`
